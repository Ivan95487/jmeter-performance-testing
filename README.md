HTTPS Performance Testing — Apache JMeter

About the Project

This project demonstrates performance testing of an HTTPS endpoint using Apache JMeter.

The goal is to evaluate server response time, stability, and behavior under load.

Tools & Technologies

* Apache JMeter 5.6.3
* HTTPS
* Docker
* GitHub

Test Scenario

The project includes an HTTPS test scenario created in Apache JMeter.

The test plan can include:

* HTTP Request
* Thread Group
* Virtual Users
* Response Time Analysis
* Results Tree

How to Run

1. Install Apache JMeter.
2. Clone this repository.
3. Open HTTPS test.jmx in JMeter.
4. Review the Thread Group settings.
5. Run the test.
6. Analyze the results.

Metrics

The following performance metrics can be analyzed:

* Average Response Time
* Minimum Response Time
* Maximum Response Time
* Throughput
* Error Percentage

Test Results

Test execution results can be added here after running the scenario.
